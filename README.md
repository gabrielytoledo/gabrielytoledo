## Projeto em andamento

### Sistema de Estoque para Restaurantes

Sistema de controle de estoque feito em Python, com cadastro de produtos, histórico de movimentações, controle de lotes e validade e regra FEFO (o lote que vence primeiro é o primeiro a sair). Os dados serão guardados em SQLite e as regras principais terão testes com pytest.

**Status:** etapa 1 de 6, lógica básica do estoque.
